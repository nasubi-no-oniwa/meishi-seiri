# 名刺の整理

奥さんが帰ってくるまで60秒。机の上の名刺を、会社の名刺は左の名刺入れへ、キャバ嬢・デリヘルの名刺は右のシュレッダーへスライドする。まちがえたら4秒止まる。

遊ぶ：https://nasubi-no-oniwa.github.io/meishi-seiri/

- `index.html` … ゲーム本体（1つのファイル）
- `database.rules.meishi.json` … ランキングのルール。GitHub に上げると自動で ft-green の `meishi` に反映（ほかのゲームのルールはそのまま）。リポジトリの Secrets に `FT_GREEN_SERVICE_ACCOUNT` が必要
- `test/rules-test.mjs` … ルールの試験（GitHub の上で試し用のデータベースを立てて試す）

## しくみ
- 名刺は6種類：会社（地味）・会社（夜っぽい派手な見た目、だじゃれの社名）・キャバ嬢・デリヘル・会社っぽい地味な見た目のキャバ嬢・デリヘル。むずかしさはずっと同じ
- 見分け方：会社の名刺には名字つきの名前と役職。お店の名刺は下の名前だけで、LINE や料金・営業時間がある
- 名刺の会社名・店名・名前はすべて架空。電話番号は使われていない形（03-0…・090-0…）、メールは `.example`
- まちがえると、その名刺を大きく見せて見分けるところを赤丸で囲み、4秒止まる（そのあいだも時間は減る）。まちがえた名刺はそのまま入る
- 60秒たつと奥さんが帰ってくる。名刺入れに夜の名刺が入っていると見つかって怒られる
- ランキングは「整理した枚数」の順。同じ枚数なら、まちがいが少ない方が上。枚数もまちがいも同じなら同じ順位（21・22・22・24）で、先に記録した人が上。並べるための数 `k` は「枚数×1000＋999−まちがい」
- 隠し結末：タイトルの「整理をはじめる」を横にずらすと「名刺入れごとシュレッダー」が出る。押すと結婚式の写真ごとシュレッダーにかけ、奥さんに切れられて終わる。人数は `meishi/zen` に1人1つ、ランキングの1位の上に「社会的地位と家庭内での地位を失った」として出る
- 始めた瞬間にサーバーの時刻を `meishi/runs/人` に書く。記録は、その時刻から55秒より前には載らない
- 消したい記録は、Firebase の `meishi/hidden/人のID` に `true` を入れるとランキングに出なくなる
- Xに投稿：リンクは結果ごとのページ `s/枚数.html`（0〜80枚。81枚からは `s/80p.html`・`s/100p.html`…、隠し結末は `s/zen.html`）。日本語以外で遊んだ人は英語の画像 `s/en/` を使う
- ランキングは上位100人だけ読む。今日の分は `ds`（日×10000000＋k）の順で読む
